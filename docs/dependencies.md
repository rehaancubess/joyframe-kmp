# Dependencies and attribution

Joyframe is Apache-2.0. Dependencies are not relicensed by this project.

- Kotlin, kotlinx.coroutines and Compose Multiplatform: JetBrains/Kotlin contributors.
- LWJGL and lwjgl3-awt: their respective authors; platform native bindings.
- JNA: its respective authors; Objective-C/OpenAL interop on desktop macOS.
- Gradle wrapper: Gradle, Inc., Apache-2.0.
- Android and Apple system APIs and browser Web APIs: supplied by their platforms.

Review dependency licenses when bundling an application. Joyframe source contains
no models, textures, recorded audio, store configuration, backend keys or private
gameplay code. The sample geometry and tone are generated in code.
